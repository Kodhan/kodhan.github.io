This site already has Spotify Connect set up — just tap 🎧 Connect Spotify and log in with your own account. You only need this screen if you specifically want to use a different Spotify Developer app instead of this site's default one (e.g. you're hosting your own copy of this project).

  1. Open developer.spotify.com/dashboard and log in with your normal Spotify account.
  2. Click Create app. Any name/description works.
  3. In Redirect URIs, add exactly this, then click Add:
    …
  4. Tick Web Playback SDK and Web API under "Which API/SDKs are you planning to use?", then Save.
  5. Open the new app's Settings, copy the Client ID, and paste it below.
